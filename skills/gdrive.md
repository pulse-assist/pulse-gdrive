# Google Drive

Плагин подключает Google Drive к каталогу файлов: папка **@gdrive** в «Файлах», у `pulse files` и в смонтированном
дереве (`$PULSE_FS_DIR/@gdrive`). Внутри — **подключения**, каждое — своя папка:

- «Мой диск», «Доступные мне» (файлы, которыми поделились), общий диск или папка в них (`mount`);
- файл или папка по ссылке (`mount link`) — от имени выбранного аккаунта; без права правки — только чтение.

```bash
pulse gdrive mounts                               # что подключено: имя → @gdrive/<имя>, откуда, только ли чтение
pulse gdrive accounts                             # аккаунты, место, не истёк ли вход
pulse files ls "@gdrive/Мой диск/Отчёты"          # дальше — обычные файлы
pulse files get "@gdrive/Мой диск/Отчёты/q3.pdf"  # скачать к себе для обработки
```

## Как устроено

- **Документы Google** (Документы, Таблицы, Презентации, Рисунки) — не файлы: в @gdrive они видны как `.docx`,
  `.xlsx`, `.pptx`, `.png` — это экспорт, **только чтение**. Читать и анализировать их можно как обычные файлы; править —
  только в Google (владелец открывает их в «Файлах» — там редактор Google). Не пытайся записать поверх них.
- **Одинаковые имена** в одной папке Drive различаются суффиксом: «план.txt», «план (2).txt».
- **Ярлыки** видны как то, на что ведут. Формы, Сайты, Карты Google — не показываются.
- Удаление — в корзину Google Диска, не навсегда.

## Правила

- **Сеть, а не диск.** Каждое обращение к @gdrive — запрос к Google. Не обходи хранилище целиком (`grep -r`, `find`
  по всему @gdrive; `pulse files find` его не ищет): иди по папкам, которые назвал владелец. Для тяжёлой обработки
  скопируй нужные файлы к себе и работай с копией.
- **Запись — по просьбе.** Класть, переименовывать и удалять файлы на Диске владельца — только когда он просит;
  перед удалением папок спрашивай. Результаты своей работы клади в свои папки Пульса, если не сказано «на Диск».
- **Доступ по ссылке** (`pulse gdrive share --path …`) открывает файл всем, у кого есть ссылка, — только по прямой
  просьбе владельца.
- **Вход делает владелец.** Пароль Google не проси и не вводи. Нужен ещё аккаунт — отправь владельца на страницу
  [Google Drive](/p/gdrive/main) → «Войти в аккаунт Google» (или `pulse gdrive login` и передай tell_owner). Если
  владелец прислал в чат адрес вида `http://127.0.0.1:1/?state=…&code=…` — заверши вход: `pulse gdrive login finish
  --url "<адрес>"`; адрес действует несколько минут, не повторяй его в ответах.
- Общий диск или папку не видно — `pulse gdrive drives`, `pulse gdrive browse --root shared`: может, нужен другой
  аккаунт или владелец ещё не получил доступ.
- «Вход истёк» или сигнал «Войдите в Google снова» — попроси владельца войти снова на странице плагина. Не отвечает
  совсем — `pulse gdrive check` покажет, где обрыв.
- Ссылка для владельца на папку: [Google Drive — Мой диск](/files?path=@gdrive/Мой%20диск) (пробелы — %20).
