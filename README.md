# Google Drive для «Пульса»

Плагин подключает Google Drive к «Пульсу»: папка **@gdrive** в «Файлах», у `pulse files` и в смонтированном дереве
агентов.

- **Несколько аккаунтов.** Вход в браузере: владелец входит в Google и вставляет на странице плагина адрес, на который
  его перекинет браузер (`http://127.0.0.1:1/?code=…`). Пароль плагин не видит; вход продлевается сам, истёк — сигнал.
- **Подключения** — папки в @gdrive: «Мой диск», «Доступные мне», общие диски, папки в них, файлы и папки по ссылке.
- **Документы Google** видны как `.docx/.xlsx/.pptx/.png` (экспорт, только чтение). В «Файлах» они — и Office-файлы
  с Диска — открываются **редактором Google** прямо в панели (правки сохраняет Google); PulseFiles+ — «⋯ → Открыть
  в…». Если браузер не пускает Google во встроенное окно (сторонние cookie закрыты) — «Открыть в Google ↗».
- **Команды агентов:** `pulse gdrive accounts | login | login finish | logout | check | drives | browse | mounts |
  mount | mount link | rename | unmount | share` — см. `commands.json`.

Удаление — в корзину Google Диска. Файлы не копируются на сервер Пульса: каждая операция — запрос к Google.

## Почему вход со вставкой адреса

Вход по коду с устройства Google разрешает только с правом `drive.file` — доступ к файлам, созданным самим
приложением; существующий Диск так не подключить. Вход «Desktop app» с возвратом на 127.0.0.1 работает на любой
установке: ни внешний адрес Пульса, ни регистрация адресов возврата не нужны.

## Приложение Google Cloud

Задаётся только в настройках плагина (`client_id`, `client_secret`) — в коде и репозитории их нет. Для доверенных
установок их выдаёт администратор Пульса; своё приложение — INSTALL.md, шаг 2 (тип Desktop app, Google Drive API,
статус **In production** — в Testing Google отзывает вход через 7 дней).

## Прокси

Если Google с сервера Пульса недоступен — настройка «Прокси для запросов к Google» (секрет; `http://…` или
`socks5://…`), по умолчанию через него идёт только вход; «Все запросы к Google через прокси» — если не отвечает и Диск.
«Проверить подключение» в настройках плагина (или `pulse gdrive check`) показывает по шагам, что работает.

## Разработка

```bash
pip install -r backend/requirements-dev.txt
pulse-plugin check
cd backend && python -m pytest          # Google подменён, сеть не нужна
```

Нужен Пульс с контрактом плагинов 1.5.
